## 一、组长身份晋升与指挥空间解锁

### 1.1 如何创建队伍并晋升组长
在高校学科竞赛与作业管理系统中，组长身份完全依据队伍归属**动态智能感知**：
1. 任何认证学生登录系统后，在个人工作台右上角点击 **【创建项目组（晋升组长）】** 按钮（或在【团队招募】广场点击【创建新团队】）；
2. 填写立项信息：
   - **团队名称**：如“极客先锋AI算法攻坚队”；
   - **所属竞赛**：选择正在进行的赛事（或暂时选留空/校级备赛）；
   - **团队简介与主攻方向**：阐明团队技术栈与备赛目标；
3. 提交成功后，系统立即为该账号授予 **`👑 团队组长`** 黄金徽章，并专属解锁工作台中的 **【👑 组长指挥空间】**！

![项目组长团队治理工作台](./images/03_leader_workspace.png)

### 1.2 【👑 组长指挥空间】全景概览
组长登录后，工作台自动平铺其带领的全部项目组卡片，每张大卡片集中承载以下指挥模块：
- **项目顶栏**：展示团队名称、所属赛事标签、参赛状态及私密开关；
- **组长工具箱**：AI战力诊断、组员私密打分、邀请成员、发布招募、小组讨论直达；
- **成员花名册**：实时展示组员身份、当前分工职责、分工变更及移出操作；
- **招募审核看板**：待审批的组员申请列表，支持即时预览简历与录取决裁。

## 二、团队精细化治理与控制权

### 2.1 团队私密状态开关（知识产权与备赛防窥）
每支团队卡片右上角均配备专属的 **【团队私密状态切换开关】**：
- **🌐 公开模式（默认）**：全校师生可在团队招募广场浏览该队伍，方便对外展示与招贤纳士；
- **🔒 私密模式（备赛保密）**：
  > 开启私密后，系统将从全校公共搜索、团队广场和列表列表中彻底隐匿该团队。只有该团队的正式组员与指导教师才具备访问权限，切实防止备赛方案与核心代码被竞品团队窥探。

### 2.2 参赛竞赛绑定与自由调整
若团队在创建之初尚未选定具体赛事，项目标签将标示为 `🏷️ 暂未参与具体赛事`：
1. 点击标题旁的 **【🎯 选择/修改参赛竞赛】** 按钮；
2. 系统弹出全校竞赛列表弹窗，支持按级别与学科筛选；
3. 组长选定目标赛事后一键绑定，团队即刻正式纳入该竞赛的申报流转与评审序列。

![团队大厅与招募广场](./images/05_project_center.png)

### 2.3 招募引才与申请审核流程
1. **发布招募引才**：
   - 点击工具箱中的【发布招聘引才】；
   - 录入招募岗位名称（如“全栈开发负责人”）、需求人数与技能要求（如“精通 Vue3、掌握 SpringBoot”），发布至全校团队大厅；
2. **入队申请审批与录取**：
   - 当其他学生在团队大厅提交入队申请后，组长工作台的【招募引才审核与组员录取】区域将出现待审批红点；
   - 查阅申请人的姓名、学号、专业及自荐申请留言；
   - 点击 **【✅ 接受组员】** 即可将候选人正式编入队伍；点击 **【婉拒】** 礼貌谢绝。

### 2.4 主动定向邀请组员加入
若组长已知晓特定优秀同学的学号或姓名：
1. 点击工具箱中的 **【邀请成员加入】** 按钮；
2. 检索目标学生的姓名或学号，发起组队邀请；
3. 该学生的工作台将即刻弹出高亮邀请横幅，对方点击接受后立即入组。

### 2.5 成员花名册治理（变更分工与组员移除）
在【项目组成员花名册】列表中：
1. **变更分工职责**：
   - 点击组员操作列的【变更分工】；
   - 录入组员的最新职责（如“核心算法工程师 / 动态规划主攻”或“测试与技术文档编制”），便于全队权责清晰；
2. **组员移除出组**：
   - 若某成员因学业原因无法继续跟进，点击【移除】并二次确认；
   - 系统将解除该成员的团队绑定，并释放成员席位。

### 2.6 🔒 组员私密绩效打分中心
为保证团队贡献考核的客观与严谨，组长享有专属的【🔒 组员私密绩效打分】特权：
1. 点击工具箱中的【🔒 组员私密绩效打分】按钮；
2. 针对各组员的阶段性表现（代码交付质量、沟通积极性、出勤率）进行星级评定与综合评分；
3. 录入客观评语，评分数据受系统严格加密保护，供指导导师评审与期末学分综合核定时调取参考。

## 三、智能化战力赋能与任务督导

### 3.1 🤖 AI团队战力诊断与胜率预测
1. 点击工具箱中的 **【🤖 AI团队战力诊断】** 按钮；
2. 系统 AI 引擎将自动全量拉取全队组员在算法题库、过往竞赛以及技术标签的大数据表现；
3. 输出智能分析报告：
   - **技术栈互补度评估**（如：前端开发 100%、算法 90%、架构设计 80%）；
   - **团队潜在短板警示**（如“图论搜索与复杂度剪枝储备较弱，建议针对性补强”）；
   - **赛事胜率与奖项预测等级**。

### 3.2 阶段性算法作业“一键催交”
1. 组长在面板中可直观查看所辖组员针对指定算法作业的完成进度分布；
2. 针对尚未提交或未通过的组员，组长点击 **【一键催交】** 按钮；
3. 系统立即向该组员的工作台派发高优先级的**红色闪烁催交通知**；
4. 只有组员在 OJ 沙箱中成功 AC 该算法题后，催交状态才会自动消除，形成督导闭环。

### 3.3 团队加密研讨群聊（💬 小组讨论）
1. 点击工具箱中的 **【💬 小组讨论】** 按钮；
2. 按钮自带未读消息红点计数器，群内有最新讨论时实时感知；
3. 点击直达团队专属研讨聊天室，全队成员可在此实时同步代码进度、探讨题解思路。

## 四、👑 组长与教师领航群协同

### 4.1 领航群专属地位与职能
为了搭建全校竞赛领军骨干与指导教师的直接沟通桥梁，系统建立了全校级 **【👑 组长与教师领航群】**。

![导师督导与教学管理驾驶舱](./images/06_teacher_workspace.png)

### 4.2 智能自动进退群机制
> [!IMPORTANT]
> **全自动领航群权限流转**  
> - **自动进群**：学生只要名下成功创建并拥有 1 个及以上竞赛项目组（即拥有组长身份），系统将**自动为其开启领航群访问权限**，工作台上方将自动激活【👑 组长与教师领航群】标签页；  
> - **自动退群**：若组长解散或移交了所有项目组，名下不再担任任何组长职务，系统将自动回收进群权限，确保领航群生态的高纯洁度与决策高效性。

### 4.3 未读消息横幅与高优先级交流
1. 当指导教师在领航群中发布竞赛最新章程、选题指导或答辩日程时，组长工作台顶部将浮动显眼的**未读消息横幅提示**；
2. 提示标示：“*组长与教师领航群有 N 条未读交流消息，点击立即前往群聊查看！*”；
3. 点击一键直达领航群，与全校顶尖导师面对面交流答疑。

## 五、组长常见问题解答 (FAQ)

> [!TIP]
> **Q1：组长可以同时带领多个不同的竞赛项目组吗？**  
> **A**：完全支持！在工作台顶部名片区会展示“👑 团队组长 (带领 N 组)”，组长空间会平铺所有项目组卡片，每支队伍独立管理、互不影响。

> [!TIP]
> **Q2：团队成员提交的代码在哪里查看？**  
> **A**：队员通过算法题库完成的代码作业，组长可在算法监控进度中直接查阅其通过状态；团队工程代码建议遵循 Git Flow 规范，通过 GitHub 仓库分支提交并统一审查合并。
