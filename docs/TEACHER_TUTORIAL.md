## 一、教师身份与导师工作台接入

### 1.1 教师账号获取与安全规范
为保障高校学科竞赛决策与教学评价的权威严肃性，系统前台的【注册新账号】通道**仅对普通学生开放**：
- **教师账号发放**：由教务管理人员在系统管理后台统一录入或指派教师角色标签；
- 教师使用专用导师账号（如 `teacher_wang`）及密码登录前台门户，系统将自动识别并为当前用户冠以 **`👨‍🏫 指导教师`** 专属尊贵紫标勋章。

![导师督导与教学管理驾驶舱](./images/06_teacher_workspace.png)

### 1.2 【👨‍🏫 导师管理工作台】驾驶舱全景
教师登录后点击顶部用户名进入个人工作台，系统将无缝激活【👨‍🏫 导师管理工作台】标签页，核心模块包含：
1. **四大核心管理快捷通道**：
   - 🏆 **发布新竞赛**：发起全校性/省级/国家级赛事规格；
   - 💻 **发布算法训练题**：面向全员下达演练作业与编程实训；
   - 📊 **综合榜单公示发布**：结项评审打分与榜单全网公示；
   - 🛡️ **社区论坛内容治理**：AI敏感拦截审核、加精与全网置顶；
2. **全体注册学生档案中心**：全校所有注册学生的学籍、战力、所报团队穿透式管理；
3. **学生竞赛荣誉证书审核认证中心**：官方线上查验学生申报的竞赛获奖证书原件；
4. **👑 组长与教师领航群**：与全校所有竞赛组长无障碍实时大群交流。

## 二、竞赛与算法教学任务发布中心

### 2.1 学科竞赛规格发布与赛程管控
1. 在导师工作台点击 **【发布新竞赛】** 快捷卡片；
2. 完整录入赛事章程规格：
   - **赛事全称**：如“2026第十四届全国大学生计算机系统与软件创新大赛”；
   - **赛事级别**：`国家级` / `省部级` / `校级重点`；
   - **赛事阶段与起止周期**：报名起止时间、初赛评审截止日、决赛答辩日；
   - **组队约束规则**：设定每队最少与最多人数限制（如 1 - 5 人）；
   - **赛题指导书与附件材料**：上传官方技术规约与申报模板；
3. 保存发布后，该竞赛即刻全网推送到前台首页【学科竞赛】大厅与热门轮播看板。

### 2.2 算法训练题录入与沙箱判题用例配置
1. 点击快捷入口 **【发布算法训练题】**；
2. 录入算法教学题目详情：
   - **题目标题与分类标签**：设定算法知识点（如 `动态规划`、`二叉树与图论`）及难度级别（`入门` / `简单` / `中等` / `困难`）；
   - **题目 Markdown 题干**：详细描述业务场景、数学模型、输入与输出规范；
   - **资源上限约束**：精确设定运行时间限制（如 1000ms）与堆内存限制（如 256MB）；
   - **沙箱测试集配置**：
     - **公开样例**：提供 1-2 组标准输入输出及解析，供学生界面自测；
     - **隐藏判题集**：录入多组边界、超大规模隐藏测试用例，确保防作弊判题准确性；
3. 发布后题目即刻收录进全校【算法题库】，供全校学生在线实战训练。

## 三、竞赛成果评审与全网榜单公示发布

### 3.1 团队成果打分与答辩评级
1. 在竞赛结项或初赛/复赛评审阶段，点击 **【综合榜单公示发布】** 卡片；
2. 系统调出该赛事下已申报的所有项目组名单及组员提交的代码报告、答辩附件；
3. 导师可对团队的**技术先进性、代码完整度、商业应用价值**执行百分制打分，并撰写评语。

### 3.2 奖项核定与全网风云榜永久公示
1. 根据评审综合得分排序，教师可一键核定最终荣誉：
   - 评定 **【特等奖】**、**【一等奖】**、**【二等奖】** 及 **【三等奖】**；
2. 点击 **【全网公示发布】**：
   - 获奖名单与答辩得分将永久固化并在前台【天梯排行榜】与竞赛详情页全校公示；
   - 获奖队伍的成员将同步收获相应的学术积分，排名直达学院天梯风云榜！

![全校荣誉天梯排行榜殿堂](./images/08_ranking_hall.png)

### 3.3 电子证书全自动防伪赋码下发
榜单全网公示发布后，系统底层证书服务将为每一位获奖团队成员全自动生成一份官方电子获奖证书：
- 证书内嵌全校统一编制的 **防伪唯一核验溯源码**（如 `CERT-2026-XN-XXXXX`）；
- 证书防伪哈希串写入不可篡改认证数据库，学生可直接下载带水印高清电子版。

## 四、全校学生档案中心与荣誉证书审核

### 4.1 全体注册学生档案中心（多维检索与穿透分析）
教师工作台专门内置了全校级【全体注册学生档案中心】：
1. **多维模糊检索**：支持在搜索框输入学生姓名、学号、所属专业或技能标签进行毫秒级筛选；
2. **学生多维透视花名册**：
   - **角色感知**：自动标记该生为普通组员还是“👑 组长 (带领 N 组)”；
   - **技能标签云**：清晰展示学生自主填写的技术栈（如 `Java, 算法, Vue3`）；
   - **团队参与度**：直观展示其当前参与的竞赛项目组数量；
3. **档案穿透**：点击【查看档案】，调阅该学生的五维算法战力雷达图及参赛履历，便于导师挑选拔尖科研苗子。

### 4.2 学生竞赛荣誉证书审核认证中心
针对学生个人在校外其他赛事中所取得的历史荣誉自主申报：
1. 在工作台的【学生竞赛荣誉证书审核认证中心】列表中，查阅待处理证书申请；
2. 点击 **【查看原件 ↗】** 在线开窗核验学生上传的荣誉证明附件文件；
3. 针对处于 `⏳ 待审核 (PENDING)` 的申报，点击 **【审核认证】** 按钮：
   - 选择 **【✅ 官方认证 (VERIFIED)】** 或 **【❌ 驳回 (REJECTED)】**；
   - 录入导师审核批注与认证备忘（如“经省组委会官网查验无误，准予学分折算”）；
4. 认证通过后，该荣誉将即刻转化为全校天梯排位加分并公示。

## 五、师生领航沟通与学术社区治理

### 5.1 👑 组长与教师领航群在线督导与领航广播
1. 教师进入工作台的 **【👑 组长与教师领航群】** 标签页；
2. 领航群汇聚了全校所有正在带队的竞赛项目组长；
3. 教师可在此直接发布赛前辅导资料、宣贯备赛纪律、解答各团队遇到的共性技术瓶颈；
4. 消息发布后，所有组长的工作台均会实时亮起高亮横幅与未读徽标。

### 5.2 学术研讨论坛深度内容治理（AI拦截过审与置顶决裁）
系统接入了 AI 智能文本风控引擎，对学生的发帖进行 7x24 小时合规预审：
1. 教师点击快捷入口 **【社区论坛内容治理】**（或直达论坛后台审核视图）；
2. **AI拦截帖人工过审**：针对被 AI 误判或存疑拦截的专业代码研讨贴，导师具有终审赦免过审特权；
3. **加精与全网置顶**：
   - 针对学生发布的极高水准算法题解（如“二叉树 LCA 递归解法深度剖析”）或优秀开源项目，导师可一键设置 **【加精】** 或 **【全站置顶】**；
   - 置顶帖子将在论坛首页最上方滚动展示，营造浓厚的高校学术创新氛围。

## 六、教师常见问题解答 (FAQ)

> [!TIP]
> **Q1：如何在线核验任意一份学生出示的防伪证书？**  
> **A**：在系统前台导航栏或工作台的【证书真伪核验】模块，输入学生证书左下角的“防伪溯源码”，系统将瞬间比对底层认证库，回显官方获奖学生、比赛名、奖项级别与发放时间。

> [!TIP]
> **Q2：若竞赛申报过程中需要追加附件或延长答辩报名时间，可以修改吗？**  
> **A**：可以。教师发布的竞赛在处于进行中状态时，可在竞赛详情页点击【编辑竞赛规格】更新报名截止时间与说明附件。
