## 第一章 学生角色（STUDENT）使用指南

学生是平台的核心受众，涵盖“竞赛申报”、“算法实训”、“团队协作”与“荣誉沉淀”完整闭环。

![学生个人工作台与AI诊断](./images/02_student_workspace.png)

### 1.1 账号注册与登录激活
1. 点击右上角【登录 / 注册】按钮；
2. 输入您的**学号**、**真实姓名**、**学院**与**班级**等信息完成学生认证；
3. 登录成功后，顶部导航栏将展示学生姓名（如“李思睿”）及专属个人头像，点击即可进入【个人工作台】。

### 1.2 算法作业在线实训与评测（Online Judge）

![算法实训中心与在线代码评测](./images/04_algorithm_center.png)

1. 点击顶部导航栏【算法题库】，进入题库大厅；
2. **多维筛选**：支持按算法分类（`动态规划`、`二叉树与图论`、`贪心与搜索`、`数学与字符串`）和难度级别（`入门`、`简单`、`中等`、`困难`）进行检索；
3. **在线实训与代码提交**：
   - 点击题目卡片（如“最长公共子序列 LCS”或“二叉树最近公共祖先 LCA”），进入实训界面；
   - 查阅题目背景、输入输出格式约束、时间/空间复杂度限制与标准样例；
   - 选择编程语言（`Java` / `Python` / `C++` / `Go`），在代码编辑器中编写算法逻辑；
   - 点击【提交评测】，系统后台沙箱将自动执行全套隐藏测试用例；
   - 判题结果即刻反馈：通过后自动更新个人通过数，并累计算法学分。

### 1.3 催交通知接收与作业状态流转
> [!IMPORTANT]
> **算法催交通知消除机制**  
> 当团队组长针对某项算法作业发起催交时，未完成队员的【个人工作台】会浮动高亮闪烁的**催交通知徽标**（如“动态规划专项作业催交”）。  
> 消除催交的唯一途径：点击通知直达对应题目完成代码提交并通过评测，系统将自动核销该催交通知并同步更新组长面板。

### 1.4 AI 算法能力成长画像与防伪荣誉证书
1. **五维能力雷达图**：
   - 工作台集成 AI 综合评估引擎，根据学生的做题正确率、算法标签分布、竞赛参与度与代码执行效率，生成专属的**动态规划、数据结构、数学几何、图论搜索、工程设计**五维战力雷达。
2. **防伪电子证书**：
   - 获奖学生可在工作台查看或下载由系统颁发的**区块链级防伪唯一核验码证书**。
   - 证书自带全校统一生成的防伪编码，任何单位或导师均可通过前台/后台直接核验真伪。

## 第二章 组长角色（LEADER）使用指南

组长是学生群体中的骨干领袖，承担着“团队创立”、“队员招募”、“分工管控”与“算法督促”的管理职责。

![项目组长团队治理工作台](./images/03_leader_workspace.png)

### 2.1 创建团队与申报竞赛
1. 点击顶部导航栏【团队招募】或直接在【学科竞赛】中选择心仪的赛事；
2. 点击【发起组队 / 创建新团队】，填写：
   - **团队名称**（如“极客先锋AI算法攻坚队”）；
   - **所属竞赛**（如“2026全国大学生计算机系统与算法挑战赛”）；
   - **团队简介与主攻方向**（如全栈开发、深度学习、算法设计）。
3. 提交后，创建者自动晋升为该团队的**队长（LEADER）**，工作台专属解锁【👑 组长指挥空间】。

![团队大厅与招募广场](./images/05_project_center.png)

### 2.2 招募令发布与成员审批
1. 进入【团队大厅】，组长可在其名下的团队卡片中发布**岗位招募令**（如招募“前端可视化工程师 1名”、“算法核心研发 1名”）；
2. 全校其他学生在团队大厅浏览时可点击【申请入队】；
3. 组长在【组长工作台】的【入队申请审批】列表中查看候选人简历，并执行【同意入队】或【婉言谢绝】。

### 2.3 队员分工指派与组员移除
1. **分工配置**：
   - 组长可随时在成员管理列表中，为具体组员（如李思睿）设定角色职责（如“核心算法工程师 / 动态规划主攻”）；
2. **成员出组治理**：
   - 若队员因故无法继续配合团队进度，组长可点击其卡片右侧的【移除成员】操作，系统将解除该成员与团队的绑定关系并释放名额。

### 2.4 算法作业与阶段任务“一键催交”
1. 组长可在此面板直观查看全队成员的算法作业完成进度条；
2. 针对存在逾期或未提交算法作业的组员，组长可点击【一键催交】按钮；
3. 系统将立即下发站内高优先级红标催流通知至该队员的工作台，并记录在催交日志中。

## 第三章 指导教师（TEACHER）使用指南

指导教师账号拥有前台高级学术与教学督导特权。教师登录后，工作台将无缝接入【👨‍🏫 导师管理工作台】。

![导师督导与教学管理驾驶舱](./images/06_teacher_workspace.png)

### 3.1 学科竞赛发布与管理
1. 在导师工作台点击【发布新竞赛】；
2. 填写完整的赛事规格：
   - **赛事名称**（如“2026第十四届全国大学生软件创新大赛”）；
   - **赛事级别**（国家级 / 省部级 / 校级重点）；
   - **报名与评审起止周期**；
   - **组队限制**（如每队 1-5 人）；
   - **赛题指南与附件规范**；
3. 保存发布后，该竞赛即刻全网推送到前台首页【热门赛事】与【学科竞赛】大厅。

### 3.2 算法题库扩展与测试用例录入
1. 点击导师工作台的【发布算法题】功能；
2. 录入题干 Markdown 文本、时间与内存上限；
3. 配置**公开样例**与**隐藏判题用例**（输入、期望输出），保存后即刻生效至全校算法 OJ 系统。

### 3.3 竞赛评审与综合榜单公示发布
1. 在竞赛结项阶段，教师进入【综合榜单公示发布】中心；
2. 针对各团队的项目报告、代码提交质量与算法成绩进行打分评级；
3. 评定【特等奖】、【一等奖】、【二等奖】等奖项，一键点击【全网公示发布】；
4. 公示发布后，该信息将在全校天梯榜与赛事大厅永久公示，并自动生成获奖证书。

### 3.4 学生电子证书防伪真伪核验
1. 教师在工作台的【证书核验】功能中，输入任一学生证书的**防伪唯一溯源码**；
2. 系统即刻调取防伪数据库，比对并返回：**获奖学生姓名、竞赛名称、奖项等级、颁发时间与防伪哈希串**；
3. 杜绝证书造假与非授权篡改。

## 第五章 常见问题与操作技巧（FAQ）

> [!TIP]
> **Q1：为什么我登录学生账号后，工作台没有“组长指挥空间”？**  
> **A**：组长身份是依据队伍创建归属动态识别的。学生只需在【团队大厅】成功创建一支队伍，系统将立即自动为您激活组长指挥空间。

> [!TIP]
> **Q2：教师账号可以在前台自己注册吗？**  
> **A**：根据学校安全规范，前台注册入口**仅对学生开放**。教师账号由系统管理员在后台管理系统统一录入，或由管理员在后台分配教师角色标签，以确保导师身份权威合规。

> [!TIP]
> **Q3：在算法在线评测时出现“运行超时（TLE）”怎么办？**  
> **A**：请检查您的代码时间复杂度。例如二叉树 LCA 题目，如果使用暴力遍历可能耗时超出上限，建议改用后序遍历或倍增法优化。
